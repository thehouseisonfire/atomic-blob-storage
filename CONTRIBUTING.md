# Contributing

Contributions are welcome through issues and pull requests at the repository
listed in `Cargo.toml`. Keep changes focused, preserve the documented durability
and trust contract, and add behavior-focused tests for observable changes.

Use conventional commit messages, update `CHANGELOG.md` for user-facing
changes, and run the formatting, test, Clippy, documentation, example, and
package checks described in `AGENTS.md`.

Changes to the V1 envelope require explicit compatibility review and updated
immutable fixtures. Native filesystem claims require evidence from the
corresponding native platform.
